# Phoenix Growth Partners Website

Official website for **Phoenix Growth Partners** — Business development and commercial growth consulting firm helping founder-led service businesses build sustainable growth systems.

## Features
- **Responsive & Modern Design**: Luxury dark theme with custom serif typography and interactive flywheel visualization.
- **Direct Form Submission**: Integrated with Web3Forms sending client enquiries directly to `phownixgrowthagency@gmail.com`.
- **Integrated Admin Panel**: Client-side content management system with password protection.
- **Cloud Database Ready**: Real-time synchronization support with Supabase.
- **SEO & Performance Optimized**: Single-file architecture with zero external runtime dependencies.
